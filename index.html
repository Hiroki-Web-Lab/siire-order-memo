仕入発注メモ

仕入一覧印刷ページの「土物」ブロックを読み取り、仕入先別の LINE 発注文を作るブックマークレットです。ページの内容を外部へ送信しません。

仕入発注メモ をブックマークバーへドラッグして登録してください。

ブックマークレットの URL

手動で登録する場合は、下の文字列をコピーしてブックマークの URL 欄に貼り付けます。

Windows / Mac（Chrome・Edge・Safari）

  1. ブラウザのブックマークバーを表示します。
  2. 上の「仕入発注メモ」リンクをブックマークバーへドラッグします。
  3. 仕入一覧印刷ページを開き、登録したブックマークを押します。

iOS Safari

  1. 任意のページを開いてブックマークに追加します。
  2. ブックマークの編集画面を開き、名前を「仕入発注メモ」にします。
  3. URL 欄の内容を消し、上の欄のローダー文字列を貼り付けて保存します。
  4. 仕入一覧印刷ページでそのブックマークを選びます。
